# قسم لابات الويب (Web Labs)

**الـBranch:** `feature/web-security-lab`
**الطلب:** دكتور مادة أمن الويب بده لاباته على NEXIS بنفس فكرة صفحة الكويز تبعته، بس بشكل مرتب ومتناسق مع الموقع.

---

## 1. شو بتعمل الميزة؟

**للطالب (صفحة Web Labs):**
1. **الامتحانات (Timed Exams):** نفس كويزات الدكتور الثلاثة. كل كويز فيه مجموعة لابات (16 و16 و13)، والطالب بياخذ **3 لابات عشوائية** ومعه **7 دقايق**.
2. **مكتبة التدريب (Practice Library):** كل لابات PortSwigger Web Security Academy (278 لاب) مقسمة حسب الموضوع، مع بحث وفلتر. كل لاب بيفتح على موقع PortSwigger.

**للدكتور (صفحة Web Lab Exams):**
- جدول مباشر بكل محاولة: الطالب، الكويز، الحالة، اللابات اللي طلعتله، واللابات اللي علّم إنه حلها.
- زر **Unlock** بيفتح الجهاز للطالب عشان يقدر يمتحن من جديد.

## 2. القواعد

| القاعدة | التفاصيل |
|---|---|
| المؤقت عند السيرفر | وقت النهاية محفوظ بقاعدة البيانات. تحديث الصفحة أو مسح بيانات المتصفح ما بيصفّر الوقت (بعكس صفحة الدكتور الأصلية). |
| اللابات عشوائية | السيرفر بيختار 3 لابات مختلفة من مجموعة الكويز. |
| امتحان واحد مفتوح | الطالب ما بيقدر يبلش كويز ثاني وهو عنده امتحان شغال أو مقفول. وقاعدة البيانات نفسها بتمنع امتحانين مفتوحين لنفس الطالب، حتى لو انبعت طلبين بنفس اللحظة. |
| القفل | لما يخلص الوقت (أو يضغط Finish Exam)، الامتحان بيتقفل وبتطلع شاشة "TIME EXPIRED" لحد ما الدكتور يعمل Unlock. |
| فتح القفل | بس حساب الدكتور بيقدر يعمل Unlock. ما في كلمة سر مكتوبة بالصفحة زي النسخة الأصلية. |
| علامة "حليته" | الطالب بيعلّم كل لاب حله. هاي المعلومة من الطالب نفسه، لأنه PortSwigger ما بيعطينا طريقة نتأكد. الدكتور بيتأكد من شاشة PortSwigger. |
| الدكتور ما بيمتحن | حساب الدكتور بيشوف مجموعات اللابات كاملة، بس ما بيقدر يبلش امتحان. |
| الحلول | تنبيه واضح: فتح قسم Solution على PortSwigger معناه صفر. ما بنقدر نكشف هاد تلقائيًا. |

## 3. الـAPIs

كلها تحت `/api/web-labs`:

| الطريقة | الرابط | مين | شو بعمل |
|---|---|---|---|
| `GET` | `/api/web-labs` | الكل | مكتبة لابات PortSwigger مقسمة حسب الموضوع |
| `GET` | `/api/web-labs/quizzes` | الكل | الكويزات الثلاثة. الدكتور بيشوف كمان مجموعة اللابات |
| `POST` | `/api/web-labs/quizzes/{quiz_id}/start` | الطالب | يبلش امتحان (201)، أو يرجع نفس الامتحان إذا كان مفتوح (200) |
| `GET` | `/api/web-labs/attempts/current` | الطالب | الامتحان المفتوح حاليًا، أو `null` |
| `POST` | `/api/web-labs/attempts/{id}/labs/{index}/solved` | الطالب | يعلّم لاب إنه انحل (`{"solved": true}`) أو يشيل العلامة |
| `POST` | `/api/web-labs/attempts/{id}/finish` | الطالب | ينهي الامتحان قبل الوقت (بيتقفل) |
| `GET` | `/api/web-labs/attempts` | الدكتور | كل المحاولات مع اسم الطالب |
| `POST` | `/api/web-labs/attempts/{id}/reset` | الدكتور | Unlock: يفتح الجهاز للطالب |

### ملاحظة لقاعدة بيانات قديمة

الجدول `web_lab_attempts` والفهرس اللي بيمنع امتحانين مفتوحين لنفس الطالب بينعملوا تلقائيًا مع بعض أول ما يشتغل السيرفر. بس `create_all` ما بيضيف فهرس لجدول موجود أصلًا.

فإذا عندك قاعدة بيانات فيها هاد الجدول من قبل الفهرس، شغّل هاد مرة وحدة:

```sql
CREATE UNIQUE INDEX IF NOT EXISTS uq_web_lab_attempts_one_open_per_user
  ON web_lab_attempts (user_id) WHERE reset_at IS NULL;
```

لما الفريق يضيف Alembic (حسب خطة GP2)، هاي الخطوة بتصير migration.

## 5. من وين إجت قائمة لابات PortSwigger؟

من الـsitemap العام لموقع PortSwigger (`portswigger.net/sitemap.xml`)، وبعدين عنوان وموضوع كل لاب من صفحته. ملف `robots.txt` عندهم بيسمح بهاد، والتحميل كان صفحة صفحة مع استراحة بين كل وحدة. خزنا العنوان والرابط بس، ولا أي نص من شرح اللابات. مستوى الصعوبة (Apprentice/Practitioner/Expert) مش موجود لأنه موقعهم بيحمّله بالجافاسكربت.

## 6. روابط مكسورة بملف الدكتور (صلّحناها)

**9 من الـ45 رابط بملف الدكتور كانت بترجع 404**، لأنه PortSwigger غيّر عناوين هاي الصفحات. يعني صفحة الدكتور الأصلية كانت بتودي الطلاب على صفحات خطأ.

- 7 منها لابات، لقيناها بنفس الاسم بالضبط بقائمة PortSwigger الحالية.
- 2 منها صفحات توثيق Burp Suite، ولقيناهم بالـsitemap.

بعد التصليح، فحصنا كل الـ45 رابط، وكلها بتفتح (200). الدكتور لازم يعرف عشان يصلّح نسخته.
