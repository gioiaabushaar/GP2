# قسم لابات الويب (Web Labs)

**الـBranch:** `feature/web-security-lab`
**الطلب:** دكتور مادة أمن الويب بده لاباته على NEXIS بنفس فكرة صفحة الكويز تبعته، بس بشكل مرتب ومتناسق مع الموقع.

---

## 1. شو بتعمل الميزة؟

**للطالب (صفحة Web Labs):**
1. **الامتحانات (Timed Exams):** الكويزات اللي الدكتور مفعّلها. كل امتحان بيعطي عدد لابات عشوائية من مجموعته (pool)، مع وقت محدد.
2. **مكتبة التدريب (Practice Library):** كل لابات PortSwigger Web Security Academy (278 لاب) مقسمة حسب الموضوع، مع بحث وفلتر.

**للدكتور (صفحة Web Lab Exams)، فيها 3 تبويبات:**
- **Live attempts:** جدول مباشر بكل محاولة (الطالب، الكويز، الحالة، اللابات، والمحلول منها)، وزر **Unlock**.
- **Exams:**
  - يعمل امتحان جديد، أو يعدّل الاسم والوصف والوقت وعدد اللابات والتعليمات.
  - يخفي الامتحان أو يظهره للطلاب، أو يحذفه.
  - يدير لابات كل امتحان: يضيف من المكتبة بالبحث أو برابط، ويشيل.
- **Library:** يضيف لاب للمكتبة، يعدّله، أو يحذفه.

## 2. وين البيانات؟ كلها بقاعدة البيانات

| الجدول | فيه | مين بيعدّله |
|---|---|---|
| `web_exams` | الامتحانات: الاسم، الوصف، الوقت، عدد اللابات، التعليمات (سطر لكل قاعدة)، ظاهر أو مخفي | الدكتور من تبويب Exams |
| `web_exam_labs` | لابات كل امتحان (العنوان والرابط) | الدكتور من تبويب Exams |
| `web_library_labs` | مكتبة التدريب (الموضوع، العنوان، الرابط) | الدكتور من تبويب Library |
| `web_lab_attempts` | محاولات الطلاب، وكل محاولة فيها نسخة من اللابات اللي طلعتلها | السيرفر لحاله |

**المحتوى الأولي:** ملفات `data/default_exams.json` و`data/default_library.json` بتنقرأ **مرة وحدة بس**، لما الجداول تنعمل لأول مرة، سواء عن طريق `create_all` أو Alembic. هيك قاعدة البيانات بتبلش وفيها كويزات الدكتور الثلاثة ومكتبة PortSwigger. بعد هيك قاعدة البيانات هي المصدر الوحيد، والإشي اللي بيحذفه الدكتور ما بيرجع.

## 3. القواعد

| القاعدة | التفاصيل |
|---|---|
| المؤقت عند السيرفر | وقت النهاية محفوظ بقاعدة البيانات، فتحديث الصفحة ما بيصفّره. |
| اللابات عشوائية | السيرفر بيختارها من مجموعة الامتحان. |
| مجموعة كافية | إذا مجموعة الامتحان أقل من عدد اللابات المطلوب، الطالب ما بيقدر يبلش (409)، والدكتور بيشوف تنبيه. |
| تعديل الامتحان | التعديل بيطبق على المحاولات الجديدة بس. المحاولة الشغالة بتحتفظ بلاباتها ووقتها. |
| امتحان مخفي | ما بيظهر للطلاب وما بينفع يبلشوه، بس الدكتور بيشوفه. |
| حذف امتحان | ممنوع إذا في طلاب امتحنوه، عشان سجلاتهم. بدل الحذف الدكتور بيخفيه. |
| امتحان واحد مفتوح | قاعدة البيانات نفسها بتمنع امتحانين مفتوحين لنفس الطالب، حتى لو انبعت طلبين بنفس اللحظة. |
| القفل | لما يخلص الوقت أو يضغط الطالب Finish Exam، الامتحان بيتقفل لحد ما الدكتور يعمل Unlock. |
| الصلاحيات | بس الدكتور بيعدّل الامتحانات والمكتبة وبيعمل Unlock. والدكتور ما بيمتحن. |
| علامة "حليته" | من الطالب نفسه، لأنه PortSwigger ما بيسمح لموقع ثاني يتأكد. |
| الروابط | لازم تبلش بـ`http://` أو `https://`. رابط المكتبة ما بيتكرر. |

## 4. الـAPIs (تحت `/api/web-labs`)

| الطريقة | الرابط | مين | شو بعمل |
|---|---|---|---|
| `GET` | `/api/web-labs` | الكل | المكتبة مقسمة حسب الموضوع |
| `POST` / `PATCH` / `DELETE` | `/library`، `/library/{id}` | الدكتور | إضافة لاب للمكتبة، تعديله، حذفه |
| `GET` | `/quizzes` | الكل | الامتحانات. الطالب بيشوف الظاهرة بس، والدكتور بيشوف الكل مع مجموعات اللابات |
| `POST` / `PATCH` / `DELETE` | `/quizzes`، `/quizzes/{id}` | الدكتور | إنشاء امتحان، تعديله، حذفه |
| `POST` / `DELETE` | `/quizzes/{id}/labs`، `/quizzes/{id}/labs/{lab_id}` | الدكتور | إضافة لاب لمجموعة الامتحان، شيله |
| `POST` | `/quizzes/{id}/start` | الطالب | يبلش الامتحان، أو يرجع نفس الامتحان المفتوح |
| `GET` | `/attempts/current` | الطالب | الامتحان المفتوح، أو `null` |
| `POST` | `/attempts/{id}/labs/{index}/solved` | الطالب | يعلّم لاب إنه انحل أو يشيل العلامة |
| `POST` | `/attempts/{id}/finish` | الطالب | ينهي الامتحان قبل الوقت |
| `GET` | `/attempts` | الدكتور | كل المحاولات مع اسم الطالب |
| `POST` | `/attempts/{id}/reset` | الدكتور | Unlock |

## 6. Alembic

```bash
cd backend && .venv/bin/alembic upgrade head
```

إذا كان عندك جدول `web_lab_attempts` من نسخة قديمة، عملته `create_all` قبل ما ينضاف الفهرس، شغّل هاد مرة وحدة:

```sql
CREATE UNIQUE INDEX IF NOT EXISTS uq_web_lab_attempts_one_open_per_user
  ON web_lab_attempts (user_id) WHERE reset_at IS NULL;
```

## 7. من وين إجت قائمة لابات PortSwigger؟

- **المصدر:** الـsitemap العام لموقع PortSwigger، وبعدين عنوان وموضوع كل لاب من صفحته. ملف `robots.txt` عندهم بيسمح بهاد، والتحميل كان صفحة صفحة مع استراحة.
- **شو خزنا:** العنوان والرابط بس، وولا كلمة من شرح اللابات.
- **مستوى الصعوبة مش موجود**، لأنه موقعهم بيحمّله بالجافاسكربت.

## 8. روابط مكسورة بملف الدكتور (صلّحناها)

9 من الـ45 رابط بملف الدكتور كانت بترجع 404، لأنه PortSwigger غيّر عناوينها: 7 لابات (لقيناها بنفس الاسم بالضبط) وصفحتين توثيق Burp. بعد التصليح كل الـ45 بتفتح. الدكتور لازم يعرف عشان يصلّح نسخته.

**الاختبارات بتغطي:**
- المحتوى الأولي موجود كصفوف بقاعدة البيانات.
- الدكتور بيعمل امتحان ويعدّله ويخفيه ويحذفه.
- مجموعة اللابات: إضافة وشيل، وامتحان بمجموعة ناقصة ما بيبلش.
- التعديل ما بيغير محاولة شغالة.
- المكتبة: إضافة وتعديل وحذف، وروابط ما بتتكرر، وإشي محذوف ما بيرجع بعد إعادة التشغيل.
- الصلاحيات.
- كل قواعد الامتحان: العشوائية، القفل، الإنهاء، الـUnlock، وطلبين بنفس اللحظة.
