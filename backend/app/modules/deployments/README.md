# قسم المواد والـDeployments

صفحة **Deploy Labs** عند الدكتور. كل بياناتها بقاعدة البيانات، والدكتور بيعدّلها من الموقع.

## الجداول

| الجدول | فيه | مين بيعدّله |
|---|---|---|
| `courses` | أسماء المواد | الدكتور: إضافة، تغيير اسم، حذف (من بطاقة Courses بصفحة Deploy Labs) |
| `lab_deployments` | سجل كل deployment: المادة، التحدي، عدد الطلاب، النتيجة (running أو refused)، والسبب | السيرفر، لما الدكتور يضغط Deploy |

- **المواد الأربعة الأولى** بتنضاف مرة وحدة بس لما الجدول ينعمل.
- **السجل بيحفظ نسخة من اسم المادة والتحدي**، فبيضل مقروء حتى لو المادة تغير اسمها أو انحذفت.

## السعة

فحص السعة صار عند السيرفر:
- **المعادلة:** (ذاكرة الجهاز − المحجوز) ÷ ذاكرة اللاب. القيم الافتراضية من خطة GP2: 32 GB، و4 GB محجوزة، و256 MB لكل لاب، يعني **112 لاب** بالأكثر.
- **التغيير:** بمتغيرات البيئة `NEXIS_HOST_RAM_GB` و`NEXIS_RESERVED_GB` و`NEXIS_LAB_MEMORY_MB`.
- **الطلب الأكبر من السعة** بينحفظ بحالة `refused` ومعه السبب.

**ملاحظة:** الـdeployment نفسه لسا **محاكاة**، يعني ما بيشغل حاويات حقيقية. هاد بيستنى الـAPI تبع حسام (FR6).

## الـAPIs (للدكتور بس)

| الطريقة | الرابط | شو بعمل |
|---|---|---|
| `GET` / `POST` | `/api/courses` | قائمة المواد، إضافة مادة |
| `PATCH` / `DELETE` | `/api/courses/{id}` | تغيير اسم، حذف |
| `GET` | `/api/deployments/capacity` | أرقام السعة |
| `GET` / `POST` | `/api/deployments` | السجل (آخر 50)، deployment جديد |

## الاختبارات

`backend/tests/test_deployments.py`: المواد الأولى، الإضافة والتعديل والحذف، منع تكرار الاسم، السعة، deployment مقبول ومرفوض، السجل بعد تغيير اسم المادة، والصلاحيات.
